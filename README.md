# AC Service Website

A professional website for AC repair and maintenance services.

## Features
- Responsive design
- Online booking system
- Service listings
- Contact forms
- Mobile-friendly

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Font Awesome Icons

## Setup
1. Clone the repository
2. Open index.html in a browser
3. No build process required
